01 // Fundamentals

What is Ransomware?

THREAT_LEVEL: CRITICAL

Core Definition

A type of malicious software designed to block access to a computer system until a sum of money is paid.

Primary Objective

"To encrypt sensitive data and use it as leverage for financial extortion through untraceable digital currency."

Encryption

Military-grade algorithms lock all user files.

Extortion

Payment demanded in anonymous Bitcoin.

Urgency

Deadlines pressure victims into quick payment.

02 // Timeline Analysis

The Outbreak

MAY 12, 2017

Initial Launch

The attack began early on a Friday, hitting organizations across Europe and Asia simultaneously.

Global Scale

Infected over 200,000 systems in 150 countries within the first 24 hours.

Worm Mechanism

Unlike typical ransomware, it was a self-propagating worm that spread automatically through networks.

Zero-Click

Required no human interaction to spread laterally once it entered a network.

03 // Technical Analysis

EternalBlue Exploit

EXPLOIT: RCE

The SMB Vulnerability

Leveraged a critical flaw in Microsoft's SMBv1 protocol. The exploit, allegedly developed by the NSA, allowed for unauthenticated remote code execution.

Target: Windows 7 & Server 2008 systems.

Method: Malicious packets sent via Port 445.

CVE-2017-0144

CRITICAL RATING

Impact: Complete system takeover with SYSTEM privileges.

Status: Patched in MS17-010 (March 2017).

"The patch was available 2 months prior to the attack, exposing massive failures in patch management."

04 // Propagation

Infection Lifecycle

WORM_FLOW
STEP 01

Scanning

Scans local networks and random IPs for open SMB Port 445.

STEP 02

Exploit

Triggers EternalBlue buffer overflow to gain system access.

STEP 03

Payload

Installs DoublePulsar backdoor to execute the ransomware.

STEP 04

Lateral

The infected host repeats the cycle on all reachable peers.

08 // Financials

Ransom & Extortion

CRYPTO_EXTORTION

The Demand

Attackers demanded $300 in Bitcoin initially, increasing to $600 if not paid within 3 days.

Anonymity was key to the model.

Low Success Rate

Despite the scale, the attackers only made around $140,000. Most victims chose restoration over payment.

Psychological Tactics

  • Fear of permanent data loss.
  • Artificial urgency via visible timers.
  • False promise of a "Decryption Guarantee".

09 // Mitigation

The Kill Switch

THREAT_HALTED

MARCUS HUTCHINS

A 22-year-old security researcher discovered a hardcoded domain in the malware's source code. By registering it for $10.69, he accidentally stopped the spread.

Logic Check

The malware checked if the domain existed. If it did, it assumed it was in a sandbox and exited.

Containment

This didn't fix already infected machines but prevented new ones from being compromised.

11 // Defense

Prevention Strategies

SAFEGUARDS

Regular Updates

Automate patching for all systems to eliminate known vulnerabilities like EternalBlue.

Data Backups

Maintain offline, immutable backups of critical data to ensure recovery without paying ransoms.

Staff Training

Educate employees on phishing and social engineering to prevent initial entry points.

12 // Attribution

The Culprits

INVESTIGATION

Lazarus Group

The US Department of Justice and other international agencies attributed the attack to the Lazarus Group, a state-sponsored hacking collective from North Korea.

"The evidence points to a sophisticated operation designed for both financial gain and geopolitical disruption."

Digital Fingerprints

  • Shared code with previous Lazarus malware.
  • C2 infrastructure overlaps.
  • Working hours consistent with North Korean timezone.
